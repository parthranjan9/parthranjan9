## 🔬 Featured Projects

### 🩺 Soft DES-ML — Chronic Kidney Disease Prediction

Dynamic ensemble selection framework using multi-target regression for patient-specific classifier weighting.

- Built a 5-model classifier pool consisting of Logistic Regression, Random Forest, SVM, Gradient Boosting and KNN
- Developed a Random Forest meta-model to predict classifier confidence
- Achieved **99% accuracy** with **100% recall** on the UCI CKD holdout dataset

---

### 🩻 Tiny Real-ESRGAN — Medical Image Super-Resolution

A lightweight ESRGAN architecture designed for 4× super-resolution of medical chest X-ray images.

- Reduced parameters from **16.7M → 4.3M**
- Reduced FLOPs from **183G → 62G**
- Reduced inference time by approximately **28%**
- Achieved **32.25 PSNR** and **0.83 SSIM**

---

### 🧠 Quantum-Fuzzy Multimodal Depression Detection

A multimodal clinical depression screening system combining NLP, audio processing and quantum-fuzzy neural networks.

- Used BERT, RoBERTa, T5, Flan-T5 and RAG for text augmentation
- Designed a PHQ-8 guided angle-encoding scheme
- Implemented a **6-qubit, 3-layer parameterized quantum circuit**
- Achieved an **F1-score of 0.87**
